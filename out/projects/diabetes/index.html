Bayesian Diabetes Risk Modelling

Comparing linear and nonlinear Bayesian logistic regression models using survey data.

RbrmsLogistic regressionLOO

Objective

Explore associations between diabetes status and blood pressure, BMI and age using BRFSS 2015 survey data.

Approach

Compare linear logistic regression with a model using splines for BMI and age.

Results

In the project evaluation, accuracy was 0.709 for the linear model and 0.712 for the nonlinear model. The balanced dataset and evaluation design limit generalisation to clinical populations.
