Electricity Consumption Forecasting

Analysing and forecasting electricity consumption in Finland using ARIMA and SARIMA models.

RTime SeriesARIMASARIMA

Objective

The aim of this project was to apply methods learned during my Time Series Analysis course to Finnish electricity consumption data and explore daily, weekly and annual seasonal patterns.

Methodology

Hourly electricity consumption data from Fingrid was analysed using MSTL decomposition, ACF, PACF and differencing. ARIMA and SARIMA models were fitted using data from 2019 to 2024.

Results

Forecast accuracy was evaluated over 24-hour and 168-hour horizons. SARIMA captured daily seasonal patterns better, while ARIMA achieved lower forecast errors during the evaluated period.

Key Findings

SARIMA captured daily consumption patterns better, while ARIMA achieved lower forecast errors over both evaluated forecast horizons.

The results showed that including seasonality in a model does not necessarily improve forecast accuracy.

Both models showed residual autocorrelation, suggesting that some patterns remained unexplained.

Limitations

Forecast accuracy was evaluated only during the first week of 2025. Temperature and public holidays were not included in the models.
